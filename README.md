# Daily Business Analysis Marketing

An end-to-end automated marketing intelligence pipeline that collects online product data, analyzes customer sentiment and performance, generates business insights using AI (Gemini), produces visual dashboards, and sends automated notifications.

This project was developed for a marketing course to demonstrate how data, analytics, and AI can support daily business decision-making.

# What This Project Does

The pipeline runs daily and performs:

## Web Scraping

- Amazon product pages (price, rating, features, BSR, etc.)

- Amazon customer reviews

- Google Trends for selected keywords

## Data Ingestion

- Cleans and normalizes timestamps

- Deduplicates reviews

- Computes VADER sentiment

- Builds a unified dataset (daily_batch.parquet)

## Analysis Engine

Computes:

- overall metrics

- sentiment per product

- top selling products (heuristic score)

- campaign risk products

- complaint keywords

- sample reviews

## AI Business Summarization (Gemini)

Generates:

- Daily business summary

- Product intelligence report

- Outputs Markdown and TXT reports

## Visualization

PNG plots:

- sentiment distribution

- polarity split

- top sellers

- campaign risks

- rating distributions

- complaint wordcloud

- Interactive HTML dashboard (Plotly)

## Notifications

- Slack

- Telegram

- SendGrid Email (with attachments)

## UI Control Panel

Streamlit interface to:

- configure scraping & ingestion

- choose ASINs

- set notification options

- launch the pipeline

# Installation

```bash
git clone https://github.com/Husseinch24/DailyBusinessAnalysisMarketing.git
cd DailyBusinessAnalysisMarketing
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

# Configuration

Gemini API

- Set environment variable:

```bash
export GEMINI_API_KEY="your_key_here"
```

- or place it in:

secrets/gemini_api_key.txt

# Notification Config

Copy template:

```bash
cp notification_config.example.json notification_config.json
```

Edit:

- from email

- to email

- enabled methods

- attachment flags

- Set SendGrid key:

```bash
export SENDGRID_API_KEY="your_sendgrid_key"
```

# Usage

- Run full pipeline:

```bash
python -m pipeline.run_daily
```

- or:

```bash
bash run_all.sh
```

- Run UI:

```bash
streamlit run ui/app.py
```
